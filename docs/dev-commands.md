# Dev Commands

```bash
./run install                 # install dependencies
./run app dev                 # run the app dev server
./run admin dev               # run the admin dev server
./run app build               # build the app
./run admin build             # build the admin
./run yarn add vue-foo        # add a dependency
./run sh app                  # shell into the app container
./run sh admin                # shell into the admin container
docker compose down           # stop the containers
docker compose logs app       # tail app logs
```
