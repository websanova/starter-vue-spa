# Dev Commands

```bash
./dev install                 # install dependencies
./dev app dev                 # run the app dev server
./dev admin dev               # run the admin dev server
./dev app build               # build the app
./dev admin build             # build the admin
./dev yarn add vue-foo        # add a dependency
./dev sh                      # shell into the app container
./dev sh admin                # shell into the admin container
docker compose down           # stop the containers
docker compose logs app       # tail app logs
```
